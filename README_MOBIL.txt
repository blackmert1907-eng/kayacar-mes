KayaCar MES — Mobil / Cloud Hazır

Telefondan PC kapalıyken açmak için uygulamanın internette barındırılması gerekir.

En kolay:
- Streamlit Community Cloud: GitHub'a yükle, app.py seç, Deploy.
- Render: render.yaml hazır; GitHub reposunu bağla.

Mobil iyileştirmeler:
- responsive telefon görünümü
- büyük dokunmatik butonlar
- dar ekran metrik/tab düzeni
- logo korunur

Not:
SQLite cloud'da kalıcı veri garantisi vermez. Gerçek üretimde PostgreSQL/Supabase/Neon
gibi kalıcı bir veritabanına geçmek gerekir.
